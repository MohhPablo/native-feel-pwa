# Security

Do not put credentials or private application data in public issues. If you discover a vulnerability, use GitHub private vulnerability reporting when enabled by the repository owner; otherwise contact the owner's listed private channel. Do not assume an email address or disclosure service exists.

The scanner reads local files without running target code or fetching URLs. It limits traversal and excludes common secrets, but cannot identify every secret filename or certify application security. Review report paths before publication. Dependencies and browser tooling are development-only; inspect their lockfile and licenses. No security guarantees are made for arbitrary host applications.
